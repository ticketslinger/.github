# TicketSlinger

We're building open-source ticketing you can run on your own server or let us run for you. Selling tickets, checking people in at the door, and the code is yours to read.

It's early. Nothing here is ready for a real event yet, and that's exactly when help counts most.

- Code: [ticketslinger/ticketslinger](https://github.com/ticketslinger/ticketslinger)
- Want to help? Start with [CONTRIBUTING](https://github.com/ticketslinger/.github/blob/main/CONTRIBUTING.md).
- Found a security problem? Report it privately: [SECURITY](https://github.com/ticketslinger/.github/blob/main/SECURITY.md).
